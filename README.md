# Simulador de Cajero Automático - Algoritmo Greedy

Simulador de cajero automático desarrollado en **Node.js** (CLI) que calcula la cantidad mínima de billetes necesarios para entregar una cantidad solicitada de dinero utilizando el enfoque voraz (**Algoritmo Greedy**).

## 🛠️ Tecnologías Utilizadas
* **JavaScript (Node.js)** - Lógica del programa y ejecución en entorno de servidor.
* **Módulo `readline/promises`** - Interfaz interactiva por consola.
* **Git y GitHub** - Control de versiones y repositorio remoto.

## 📋 Denominaciones Disponibles (C$)
* 1,000
* 500
* 200
* 100

## 🚀 Instrucciones de Instalación y Ejecución

1. Asegúrate de tener instalado **Node.js** en tu equipo.
2. Clona este repositorio o descarga los archivos del proyecto.
3. Abre la carpeta del proyecto en la terminal.
4. Ejecuta el programa con el siguiente comando:
   ```bash
   node index.js
